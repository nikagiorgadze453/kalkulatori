# შენი წილი — კალკულატორი

რეაქტიული, მობილურზე ოპტიმიზებული ვებ-კალკულატორი Excel-შაბლონის მიხედვით (`შენი წილი ჯიქიაზე`).

## ფორმულები

- **V (შენი წილი, $)** = `(C ÷ B) × A × D`
- **X (მიწის სრული ფასი, $)** = `D × A`

სადაც:

- **A** — სრული მიწა (მ²)
- **B** — სრული ნაგებობა (მ²)
- **C** — პირის ფართი (მ²)
- **D** — ფასი / მ² ($)

## ლოკალურად გაშვება

ფაილი არის სტატიკური HTML, ნებისმიერი მცირე სერვერით გაიხსნება:

```bash
# Python
python -m http.server 5173

# ან npx
npx --yes serve .
```

შემდეგ გახსენი http://localhost:5173
